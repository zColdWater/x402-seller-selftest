Can someone get your paid content without paying you?

A one-file self-test for the server side of x402. It sends unpaid route variants and forged payments at your own endpoint and tells you whether it handed out the paid response anyway.

Run it

Node 18+. Nothing to install. It is a single file you can read first.

curl -fsSLO https://raw.githubusercontent.com/zColdWater/x402-seller-selftest/main/x402-seller-selftest.mjs

# passive: fetch and lint your 402 challenge
node x402-seller-selftest.mjs https://your-api.example/paid --marker 'text only in the paid response'

# active: route variants + forged payments (no money moves)
node x402-seller-selftest.mjs https://your-api.example/paid --marker '…' --active --i-own-this

Funded checks, testnet only (replay, underpayment, client-chosen amount or payTo, concurrency):

X402_TEST_KEY=0x<test-wallet-key> node x402-seller-selftest.mjs https://staging.example/paid \
  --marker '…' --funded --i-own-this

The seller checklist

  1. Deliver only on a confirmed settlement: success === true with a tx hash, or an on-chain check (AuthorizationUsed plus a Transfer to your payTo). Timeouts, 5xx and non-JSON responses are unknown, not paid.
  2. Verify against your own requirements, never the client's accepted.
  3. Check locally first: to == payTo, value >= price, validity window.
  4. One authorization, one delivery, including under concurrency.
  5. Paywall what the router serves: every method and every path spelling that reaches the handler.
  6. Fail closed and quietly: 400 for malformed, 402 for unverifiable, no paid content in error bodies.
  7. Publish a correct challenge: atomic amounts, EIP-55 payTo, and the token's real EIP-712 domain (USDC on Base: "USD Coin"/"2").

The full checklist, CI usage and in-process testing for Workers and Hono are in the README. Background: the x402 HTTP transport spec and arXiv:2605.11781.

Safety

Only test endpoints you own or are authorized to test. Active and funded modes refuse to start without --i-own-this. Passive and active modes never move money. Funded mode refuses mainnet. A clean run is not an audit.
